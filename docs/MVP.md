# PakuLog MVP チェックリスト

PakuLogのMVPに含める機能と、その実装状況を管理するチェックリストです。
個別の実装作業と議論はGitHub Issueで管理し、この文書ではMVP全体の進捗を確認します。

## 進捗管理ルール

- 個別の実装作業と議論はGitHub Issueで管理する
- MVPのリリース進捗はGitHub Milestoneで管理する
- 機能を実装するPRでは、この文書の対応するチェック項目も更新する
- `[x]`は実装がmainへマージ済み、`[ ]`は未実装を表す

## 仕様とスコープ

- 1回の登録につき食品1件を記録する
- 食品、摂取量、摂取日時を入力項目とする
- 食品はMEXT食品成分表から選択する
- 摂取量は0.1〜9999.9 gとし、桁別ホイールと数値入力を併用する
- 1日を日本時間の00:00〜23:59で区切り、日時をUTCで保存する
- 集計対象をエネルギー、たんぱく質、脂質、炭水化物、食物繊維、食塩相当量とする
- 健康な18歳以上の成人を対象とする
- 自由入力食品、料理・献立、単位換算、画像認識をMVP対象外とする
- 妊娠・授乳期、疾病別の食事管理、減量・増量目標をMVP対象外とする
